# Testing Build - April 28, 2026

## Version: v1.0 (April 28)

### Installation
1. Download APK from Google Drive (will build for tsting purposes)
2. Install on Android phone
3. Allow "Install from Unknown Sources" if prompted

### Test Scenarios

#### Basic Flow
1. Open app
2. Tap "Add Floorplan"
3. Select test floorplan image
4. Wait for processing (green checkmark)
5. Tap to open
6. Tap your starting location
7. Tap destination
8. Tap "Start Navigation"
9. Walk and watch arrow move

#### What to Test
- Can you select points easily?
- Does route avoid walls?
- Is time estimate reasonable?
- Does arrow move smoothly?
- Do you arrive at destination?

#### Known Issues
- Movement might be slightly fast (working on it)
- Time sometimes shows "0 min" for very short routes
